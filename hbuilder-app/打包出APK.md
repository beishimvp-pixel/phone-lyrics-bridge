# 用 HBuilderX 打出手机 APK

## 先分清：编译成功 ≠ 打出 APK

控制台出现「项目 xxx 编译成功」只说明前端编译过了。  
**APK 必须走云打包**，菜单是：

**发行 → 原生 App-云打包 → Android**

不是「运行到手机/模拟器」，也不是只点保存。

## 正确步骤（当前约 1.5.3）

1. HBuilderX 打开目录 `hbuilder-app`（不要只打开上层文件夹）
2. 菜单：**发行 → 原生 App-云打包**
3. 勾选 **Android**
4. 证书选 **使用公共测试证书** / **使用云端证书**（任选能过的）
5. 等云端排队结束，状态变为成功后 **下载 APK**
6. 手机覆盖安装，再开「设备和应用通知」+「忽略电池优化」

## 若云打包失败

把 HBuilder 控制台里 **红色报错全文**（尤其含 `uts` / `Number` / `Int` / `Kotlin`）复制发我。  
只发「编译成功」那几行无法判断。

常见处理：

- 报 `Number but Int expected`：UTS 里整数必须标成 `Int`
- 一直排队/失败：换网络或稍后重试；确认已登录 DCloud 账号
- 下载不到：云打包记录页里找本次任务的 APK 链接

## 红米权限（息屏续传）

1. 应用信息 → 允许受限制的设置（若开关灰）
2. 设备和应用通知 → 允许「歌词桥」
3. 省电策略 → **无限制** / 忽略电池优化
4. 同步时不要划掉「正在同步到电脑…」常驻通知
