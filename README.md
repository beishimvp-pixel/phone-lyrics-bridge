# 歌词桥 Phone Lyrics Bridge

手机用 QQ 音乐 / 汽水 / 网易云 / 酷狗正常听歌，**电脑桌面同步显示歌词**。声音仍从手机出，电脑只负责显示。

附加（需在手机 App 里手动切换来源）：B 站字幕、番茄听书章节标题。

**网络要求：** 电脑与手机连同一局域网（同一路由器即可；电脑可网线，手机 Wi‑Fi）。

---

## 你需要两样东西

| 端 | 是什么 | 从哪来 |
|----|--------|--------|
| 电脑端 | Windows 客户端 `歌词桥.exe` | 本仓库 `pc/` 自行打包，或用已有成品 exe |
| 手机端 | Android APK「歌词桥」 | 用 HBuilderX 打开 `hbuilder-app/` 云打包 |

> 仓库**默认不附带**已编译的 exe / APK（体积大且易过期）。下面有打包步骤。

项目结构：

| 目录 | 说明 |
|------|------|
| `pc/` | Windows 桌面客户端（Python / 可打成 exe） |
| `hbuilder-app/` | 手机端 uni-app 工程（日常用这个打 APK） |
| `android/` | 早期 Android Studio 源码备份，一般可忽略 |

## 快速上手（给普通用户）

### 1. 电脑：启动客户端

**已有 exe：** 双击 `歌词桥.exe`。

**没有 exe、从源码跑：**

```bat
cd pc
pip install -r requirements.txt
run.bat
```

**自己打 exe：**

```bat
cd pc
build_exe.bat
```

成品在 `pc/dist/歌词桥.exe`。

打开后记住窗口里显示的 **本机 IP**（形如 `192.168.x.x:8765`）。

若手机连不上：

- 先开电脑客户端，再开手机同步
- Windows 防火墙放行 **入站 TCP 8765**
- 手机不要连「访客 Wi‑Fi」/ 与电脑不同网段

### 2. 手机：安装 APK 并同步

用 [HBuilderX](https://www.dcloud.io/hbuilderx.html) 打开目录 `hbuilder-app`，按  
[`hbuilder-app/打包出APK.md`](hbuilder-app/打包出APK.md) 做 **发行 → 原生 App-云打包 → Android**。

装好后：

1. 打开「设备和应用通知」权限，允许「歌词桥」读取通知  
2. 建议：**忽略电池优化 / 省电无限制**（否则息屏易断）  
3. 填入电脑 IP → 选来源（QQ / 汽水 / 网易云 / 酷狗）→ **开始同步**  
4. 用对应音乐 App 播放；电脑应出现桌面歌词  

当前工程版本约为 **1.5.3**（以 `hbuilder-app/manifest.json` 为准）。

## 桌面歌词怎么用

- **平时：** 只显示歌词字，背景透明（类似 QQ 桌面歌词）  
- **鼠标移上去：** 底部出现「按住拖动」条，可拖到任意位置（含副屏）  
- **鼠标移开：** 拖动条自动收起  
- **右键歌词：** 立刻隐藏桌面歌词  
- **再显示：** 主窗口点「开启桌面歌词」，或快捷键（默认 `Ctrl+Alt+H`，可在窗口里改）  
- **样式：** 主窗口可调字号、颜色、描边、透明度、偏移等，会记住下次启动  

### 什么时候会自动隐藏

| 情况 | 行为 |
|------|------|
| 正在播放 | 一直显示 |
| 暂停 | 约 **60 秒**后自动隐藏 |
| 长时间收不到手机状态 | 约 **3 分钟**后视为过期并隐藏 |
| 你右键关掉 / 主窗口关掉桌面歌词 | 保持关闭，直到再手动打开 |

## 手机端行为说明

- 同步时会有一条常驻通知「正在同步到电脑…」，**不要划掉**（划掉后息屏容易断）  
- 断线后约数秒自动重连；界面若显示「连接中」请稍等  
- 息屏续传依赖系统放行通知与后台；红米 / 小米等请把省电设为无限制（详见打包文档）

## 排查

| 现象 | 处理 |
|------|------|
| 手机连不上 / 一直重连 | 核对 IP；电脑先启动；同局域网；防火墙放行 8765 |
| 一直「等待播放」 | 通知使用权已开；所选来源的 App 正在播放并出通知栏信息 |
| 有歌名无歌词 | 冷门曲可能匹配失败；换一首热门歌试 |
| 息屏后电脑停更 | 忽略电池优化；保留常驻通知；升级到 1.5.2+ |
| 歌词慢半拍 | 主窗口可调时间偏移；本身约有约 0.5s 采样间隔 |
| 桌面歌词点一下就没了 | 请用最新 exe；右键是故意隐藏，用快捷键或主窗口再开 |
