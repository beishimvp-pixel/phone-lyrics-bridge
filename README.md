# 歌词桥 Phone Lyrics Bridge

手机用 QQ 音乐正常播放，电脑桌面同步显示歌词。手机停止播放后，电脑歌词自动消失。

附加：同一套桥也可同步 B站字幕、番茄听书章节标题（有 QQ 会话时仍优先跟 QQ）。

适合：电脑网线、手机 Wi‑Fi（同一路由器即可）。

## 组成

| 端 | 作用 |
|----|------|
| `pc/` / 桌面 `歌词桥.exe` | Windows 桌面客户端 |
| `hbuilder-app/` | 手机端（用 HBuilderX 云打包 APK） |
| `android/` | 旧版 Android Studio 源码备份 |

## 一、电脑端（Windows 客户端 / exe）

**直接用打包好的客户端：**

- 双击桌面上的 `歌词桥.exe`，或  
- `phone-lyrics-bridge/pc/dist/歌词桥.exe`

打开后是原生窗口（不是网页）：显示本机 IP、连接状态、当前歌词预览；播放时另有置顶桌面歌词层。

把窗口里的 **本机 IP** 填进手机 App。若连不上：防火墙放行 **入站 TCP 8765**，手机与电脑同一路由器。

**开发者重新打包：**

```bat
cd pc
build_exe.bat
```

或未打包时：`pc/run.bat`（需已装 Python）

## 二、手机端（用你电脑里的 HBuilderX 打 APK）

工程在 `hbuilder-app/`（uni-app，dir-2 红黑白样式）。

详见：`hbuilder-app/打包出APK.md`

简要步骤：

1. HBuilderX → 打开目录 `hbuilder-app`
2. **发行 → 原生 App-云打包 → Android**
3. 下载 APK 装到手机
4. 开「设备和应用通知」→ 填电脑 IP → 开始同步 → 用 QQ 音乐播放

（`android/` 是早期 Android Studio 源码备份，日常打包用 HBuilder 即可。）

## 行为说明

- 声音仍从**手机**出来，电脑只显示歌词
- **主功能 QQ音乐**：可选同步来源；QQ 曲库 → LRCLIB
- **附加 B站 / 番茄听书**：在 App 内手动切换来源
- 同步时前台常驻通知保活；断线约 3 秒自动重连
- 桌面歌词窗口可拖动；无播放时自动隐藏

## 排查

| 现象 | 处理 |
|------|------|
| 手机显示连接错误 | 核对 IP；电脑先启动；关访客网络；放行 8765 端口 |
| 一直「等待播放」 | 确认通知使用权已开；QQ 音乐正在播放 |
| 有歌名无歌词 | 冷门曲可能匹配失败，换热门歌试一下 |
| 歌词慢半拍 | 正常会有约 0.5s 采样间隔；后续可加偏移设置 |
