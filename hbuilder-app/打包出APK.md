# 用 HBuilderX 打出手机 APK

## 为什么设置里找不到「歌词桥」

系统「设备和应用通知」只会列出**声明了通知监听服务**的 App。  
旧版 APK 缺这个服务，所以列表里没有。已补上，需要**重新云打包并覆盖安装**。

## 重新打包

1. HBuilderX 打开 `hbuilder-app`
2. **发行 → 原生 App-云打包**
3. 证书选 **使用云端证书**
4. 打包下载新 APK，装到手机（覆盖旧版）

## 红米上开启权限

1. 若开关是灰的：  
   **设置 → 应用设置 → 应用管理 → 歌词桥 → 右上角 ⋮ → 允许受限制的设置**
2. 再进：  
   **设置 → 隐私与安全 → 其他权限 → 特殊权限设置 → 设备和应用通知**  
   （或设置里搜：`设备和应用通知`）
3. 在 **不允许** 列表找到 **歌词桥**，打开允许
4. 回到 App → 已开启，继续
5. 建议再开：应用信息 → 省电策略 → **无限制**（锁屏后仍要同步歌词时）

## 1.1.0 起

- 同步时会有「正在同步到电脑…」常驻通知（前台保活）
- 电脑断开后会自动重连
- 需重新云打包覆盖安装

## 云打包 UTS 再报 Number / Int

安卓原生 API 要 **Int**。改 `uni_modules/**/*.uts` 时：

- 循环下标写成 `let i: Int = 0`
- `List.get`、`startForeground`、图标 id 等参数用 **Int**
- 不要用未标注类型的 `for (let i = 0; …)`（会变成 Number，云打包失败）
