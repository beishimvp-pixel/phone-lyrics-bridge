# 六个候选方向卡

## A1 · 最佳设计师｜Teenage Engineering 思维
- **借的是什么**：一屏一种强调色、点阵读数、方格控件、像硬件面板
- **主角素材**：伪点阵进度 + 丝印小标签
- **骨架**：上半读数（歌名/进度），下半 2×2 操作键；电脑端像机架调音台条
- **胆量**：整套 UI 像一块随身监听器
- **form**：歌词桥本质是「跨设备监听」，硬件面板语言贴题材

## A2 · 最佳设计师｜佐藤可士和思维
- **借的是什么**：半屏巨符号 + 半屏极简信息；最多三色
- **主角素材**：巨字「词」
- **骨架**：左/上品牌符号区，右/下纯操作；手机启动屏几乎只有一个字
- **胆量**：用一个字讲完产品
- **form**：产品承诺就是「词出现在桌面」

## B1 · 现实参照｜Things 3 / Native Polish（同媒介 App）
- **借的是什么**：白纸感列表、发丝分隔、单一蓝色动作、浮起卡片
- **主角素材**：干净状态列表（步骤即界面）
- **骨架**：竖向步骤清单 + 底部主按钮；电脑端浅色工作台
- **胆量**：几乎无装饰，靠排版秩序
- **form**：同步就是三步待办，界面就做成待办

## B2 · 现实参照｜Halide / Pro Camera 工具感（同媒介专业工具）
- **借的是什么**：深底、单黄焦点、刻度读数、单手操作区
- **主角素材**：横向进度刻度尺
- **骨架**：上半「取景」式歌词预览，下半参数行（IP / 延迟 / 状态）
- **胆量**：黄色只点「正在同步」一处
- **form**：跟词要准，像对焦一样校进度

## C1 · 秒数轮盘｜App #11 柔和鼓励式 Gentle Encouragement
- **来源**：S=34 → App `34%12+1=11`
- **借的是什么**：深夜蓝、大圆角、粉彩状态、不评判文案
- **主角素材**：一条「同步路径」曲线
- **骨架**：竖向大圆角卡片堆叠
- **胆量**：把「断开/暂停」写成休息而非失败
- **form**：办公听歌不该焦虑，状态要温柔

## C2 · 秒数轮盘｜East #11 佐藤可士和极简符号（与 A2 同源，作变体备选）
- **来源**：East `34%12+1=11`
- **借的是什么**：满铺色块标志 + 纯白信息栏
- **骨架**：手机竖分两截；电脑左色条右内容
- **胆量**：朱红满铺半屏
- **form**：同 A2，备选执行强度不同
