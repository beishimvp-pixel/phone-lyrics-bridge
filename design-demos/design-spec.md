# 歌词桥 · 设计 Spec

## 项目是什么
把安卓 QQ 音乐「正在播放」同步到 Windows 桌面歌词。声音在手机，电脑只显示歌词；停止后歌词自动消失。

## 受众与场景
一个人边用电脑办公/写东西，边用手机听歌，希望桌面跟词、少打断。

## 核心信息
1. 填电脑 IP → 授权通知使用权 → 开始同步
2. 同步中能看见：歌名、连接状态、电脑端歌词预览
3. 停止播放 → 电脑歌词消失（产品承诺）

## 情感基调
安静陪伴、像一块小监听器，不喧哗。

## 输出格式与尺寸（三版统一）
- 单文件 HTML 展示板（可双击打开）
- 同时展示：**手机 App 4 主屏**（连接 / 授权 / 同步中 / 已暂停）+ **电脑端控制台 1 屏**
- 手机框约 390×844；电脑面板约 960×640
- 可点击切换关键状态（连接开关、授权完成等）

## 约束
- 中文界面；真实文案（歌词桥、通知使用权、局域网 IP）
- 无品牌 VI / logo，产品名「歌词桥」
- Assumption：默认深色桌面工作环境；用户可接受「工具感」

## 图片需求
无需装饰性摄影。歌词句、波形/进度用程序化图形即可。
